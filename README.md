# ATM-Simulator_Pyhon

A Command Line Interface (CLI) application built in Python that simulates an Interactive Teller Machine (ATM). This project demonstrates state management using function returns, modular logic, parameter passing, and robust input validation.


- **Balance Inquiry:** Displays current account balance formatted.
- **Deposit Funds:** Validates positive input amounts and updates the total balance.
- **Withdraw Funds:** Verifies sufficient account balance before completing transactions to prevent negative balances.
- **Input Validation:** Prevents crashes from invalid string inputs or negative numbers using `try...except` and loops.
- **Interactive Menu:** Clean control flow using Python's `match/case` statement.

## 🛠️ Built With

- **Python 3.10+**
